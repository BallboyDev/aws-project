# IAM 
- IAM은 AWS 리소스에 대한 액세스를 안전하게 제어하고 관리할 수 있게 해주는 웹 서비스이다.
- IAM을 사용하면 어떤 사용자(인증)가 어떤 리소스에 대해 어떤 작업을 수행할 수 있는지 (권한 부여) 세밀하게 제어 할 수 있다.
- AWS 계정을 생성하면 기본적으로 계정 전체를 제어할 수 있는 단일 루트 사용자가 생성되는데, 보안을 위해 루트 사용자 대신 IAM 사용자를 생성하여 사용하는 것이 좋다.

### AWS 관리 방법
-  AWS 관리 콘솔
    - AWS 관리 콘솔에서는 AWS 리소스를 생성하고 관리하는 데 사용할 수 있는 웹 기반 사용자 인터페이스를 제공한다.
-  AWS CLI
    - AWS CLI는 AWS 서비스를 관리하는 통합 도구이다.
-  AWS SDK
    - AWS SDK는 AWS 리소스를 프로그래밍 적으로 사용하기 편리하도록 제공되는 라이브러리이다.

### AWS API
- AWS API는 AWS가 제공하는 모든 서비스와 프로그래밍 방식으로 상호작용하기 위한 API들의 집합을 의미한다.
- AWS 관리 콘솔에서 버튼 클릭 등을 통해 인스턴스를 만드는 등 모든 액션도, 내부적으로 AWS API 를 호출하여 실행한다.

### IAM 구성 요소
- AWS 계정 루트 사용자
    - 처음 생성된 AWS 계정으로 해당 계정의 모든 권한을 가지고 있다.
- IAM 사용자
    - 별도의 AWS 계정이 아닌 계정 내 사용자로, 각 IAM 사용자는 자체 자격 증명을 보유한다.
    - IAM 사용자 마다 특정 AWS 작업을 수행 할 수 있게 권한을 통제할 수 있다.
- IAM 그룹
    - IAM 사용자 집합을 의미하며, IAM 그룹에 권한을 지정해서 다수의 IAM 사용자의 권한을 쉽게 관리할 수 있다.
- IAM 정책
    - 자격 증명이나 리소스와 연결될 때 요청을 허용하거나 거부할 수 있는 권한을 정의하는 AWS 객체이다.
- IAM 역할
    - 특정 권한을 가진 계정에 생성할 수 있는 IAM 자격 증명이다.
    - 역할에는 그와 연관된 암호 또는 접근 키 같은 장기 자격 증명이 없지만 역할을 주면 역할 세션을 위한 임시 보안 자격 증명을 제공한다.
    - 역할을 이용하여 일반적으로 AWS 리소스에 접근할 수 없는 사용자, 애플리케이션, 서비스에 접근 권한을 위임할 수 있다.
- 보안 주체
    - AWS 계정 루트 사용자, IAM 사용자, IAM 역할을 이용하여 로그인하고 AWS에 요청하는 사람 또는 애플리케이션

### IAM 사용자
- IAM 사용자는 일반적으로 루트 사용자와 일반 IAM 사용자로 나뉜다.
- 루트 사용자는 AWS의 모든 리소스에 접근할 수 있는 전체 권한이 있어 AWS 계정 생성 및 해지와 IAM 사용자 관리 등에 사용되지만, 보안상 직접 AWS 리소스를 사용하는걸 권장하지 않는다.
