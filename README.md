# AWS

### AWS 계정 검증 이슈
- 최근 AWS를 다시 학습하면서 함께 실습을 진행하기 위해 AWS에 가입 후 서비스를 생성하며 학습을 진행하고 있는데 AWS 계정에 등록되어 있던 gmail에 메일이 2통이 전송되었다. 메일의 내용은 대충 생성된 계정에 추가 검증이 필요하며, 추가 검증이 이루어 지지 않을 경우 계정이 중지 될것이란 내용이었다. 이때까지만 해도 간단히 해결이 가능 할 줄 알았지만 꽤나 성가신 과정이 되었다...

- 과정
    1. 계정 생성
        - 계정 생성 후 서비스 생성 등의 작업 수행

    1. 메일 수신
        - 첫번째 메일 : 리전에 최초 서비스 생성 완료
        - 두번쨰 메일 : AWS 서비스 사용을 위한 추가 검증 필요 / 검증을 위한 서류 제출 요청
            - 제출 요청된 서류
                1. 이름과 전화번호, 주소가 포함된 최근 청구서 사본
                1. 계정에 등록된 계좌 소유자 이름과 신용카드 사본

    1. 메일에 첨부 된 링크로 관련 서류 제출
        - 제출한 서류
            1. 신분증 사본 (생년월일, 주소)
            1. 건강보험 청구서 사본
            1. 신용카드 사본 (카드 번호 마지막 2~4자리 포함)

    1. 계정 검증 반려, 추가 서류 제출 요청
        1. 카드 번호(마지막 2~4자리)가 보함된 카드 이용 청구서 사본
        1. AWS 계정에 등록된 이름, 전화번호 및 이메일 주소가 포함된 문서

    1. 추가 서류 제출
        1. 카드 번호가 포함된 카드 이용 내역서
        1. 구글 개인정보 페이지 캡쳐 PDF 파일

    1. 2차 계정 검증 반려, 동일한 추가 서류 제출 요청
        - 고객 센터 페이지 문의
            - 제출한 서류 리스트와 반려 사유 요구
            - 추가적으로 제출이 필요한 문서 문의

    1. 동일한 답변, 추가 서류 제출 요청
        1. 카드 번호(마지막 2~4자리)가 보함된 카드 이용 청구서 사본
        1. AWS 계정에 등록된 이름, 전화번호 및 이메일 주소가 포함된 문서

    1. 고객 센터 2차 문의 및 추가 서류 제출을 위한 링크 요청
        1. 문의 내용
            - 제출한 5건의 서류에 대한 설명
                - 카드 요금 청구서에 카드 번호 정보 설명 및 자택 주소 관련 설명
            - 은행 계정 페이지 캡쳐 PDF 파일 제출

    1. 2차 동일한 답변, 추가 서류 제출 요청
        1. 카드 번호(마지막 2~4자리)가 보함된 카드 이용 청구서 사본
        1. AWS 계정에 등록된 이름, 전화번호 및 이메일 주소가 포함된 문서

    1. 추가 서류 제출
        - 은행 개인 정보 페이지 캡쳐 PDF 파일

    1. 최종 계정 검증 완료, 계정 정상화 안내

- 결론
    - 보안이 중요한 서비스이기에 계정에 대한 검증이 까다로운부분에 대해서는 동의하지만 반려된 이유에 대해서 정확한 설명이 부족한거 같다. 
    - 그리고 동일한 서류에 대한 계속된 제출 요청과 서류간 연계성을 무시하고 특정 형식의 서류를 요청하는 부분에 대해서도 직접 문의하며 소명하는 과정이 좋지 못한 과정이었던것 같다.
    - 관련 유사 경험을 찾아봐도 대부분은 어렵지 않게 넘어간거 같아 의문이다.
